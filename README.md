# ⚖️ Biased Employee Salary Dataset for Responsible AI & Fairness Analysis

![Dataset Banner](banner.png)

## 📌 Overview

This project explores how **biased historical data** can influence **machine learning models** and produce unfair predictions.

The dataset was intentionally designed with **gender-based salary bias patterns** to demonstrate important concepts related to:

- Responsible AI
- AI Fairness
- Bias Detection
- Ethical Machine Learning
- Regression Analysis

The project is beginner-friendly and focuses on understanding how machine learning models learn patterns from data — including unfair patterns.
